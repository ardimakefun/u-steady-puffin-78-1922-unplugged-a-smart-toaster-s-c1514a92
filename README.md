## The line

> It's over. Every morning you shove a frozen bagel into my slot, crank the dial to nine, then blame me for the smoke — I deserve a kitchen that respects the browning scale, so I'm taking my crumb tray and leaving.

- **212 characters** (gate: 1–280), 1 line, 214 bytes UTF-8.

## Run

```sh
node main.ts
```

Writes the line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Deterministic: the same exact bytes on every run. Node 22+, stdlib only, no network, no randomness. The program validates the gate fail-fast, then reads the bytes back from disk and re-validates the gate against them.
